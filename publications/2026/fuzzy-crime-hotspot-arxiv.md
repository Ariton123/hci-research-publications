# A Fuzzy Logic Framework for Community-Aware Crime Hotspot Detection: Prototype Application Architecture and Exploratory Validation for an Urban Computing Platform

## Publication

**Title:** A Fuzzy Logic Framework for Community-Aware Crime Hotspot Detection: Prototype Application Architecture and Exploratory Validation for an Urban Computing Platform

**Authors:** Ariton Verush, Vaibhav Motwani

**arXiv ID:** 2607.16218

**arXiv Link:** https://arxiv.org/abs/2607.16218

**Subjects:** Computers and Society (cs.CY); Human-Computer Interaction (cs.HC)

## Background

This paper was developed from design work, prototype architecture, evaluation material, and findings collected during an Urban Computing seminar project.

The work examines a fuzzy logic-based framework for community-aware crime hotspot detection and real-time notification within an urban computing platform. It connects fuzzy risk modeling, citizen reporting, historical crime data, contextual urban indicators, localized notifications, privacy safeguards, usability, trust, and human-centered evaluation.

The paper contributes a responsible, human-centered framework for future research on fuzzy logic, urban computing, and community-aware crime prevention systems. It is positioned as a framework and exploratory validation paper rather than as evidence of deployed crime reduction or real-world predictive accuracy.

Supporting technical and project materials are preserved separately in the engineering portfolio to avoid duplicating the original project artifacts.
