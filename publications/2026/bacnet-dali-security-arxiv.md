# Security and Human-Centered Assessment of BACnet-Controlled DALI Infrastructure in an Educational Building Automation Testbed

## Publication

**Authors:** Ariton Verush

**arXiv ID:** 2606.17089

**arXiv Link:** https://arxiv.org/abs/2606.17089

**Subjects:** Cryptography and Security (cs.CR); Human-Computer Interaction (cs.HC)

## Background

This paper was developed from technical experimentation, documentation, and findings collected during the Domotics Hackathon 2026 in Thun, Switzerland.

The work examines the security and human-centered dimensions of BACnet-controlled DALI infrastructure within an educational building automation testbed. It connects practical building automation experimentation with security assessment, protocol analysis, engineering-tool usability, and cyber-physical infrastructure research.

Supporting technical materials are preserved separately in the engineering portfolio under `hackathons/domotics-hackathon-2026-thun/` to avoid duplicating the original project artifacts.
