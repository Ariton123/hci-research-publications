# A Benchmarking Framework for Multimodal User Interface Toolkits

## Publication

**Title:** A Benchmarking Framework for Multimodal User Interface Toolkits: Comparing Modality Coverage, Developer Workflow, and Experimental Support

**Author:** Ariton Verush

**arXiv ID:** 2606.02977

**arXiv Link:** https://arxiv.org/abs/2606.02977

**Subjects:** Human-Computer Interaction (cs.HC), Software Engineering (cs.SE)

## Background

This paper was revised and expanded from an HCI seminar draft into a benchmarking framework paper focused on multimodal user interface toolkits.

The work compares modality coverage, developer workflow, and experimental support across representative toolkits, contributing to research at the intersection of Human-Computer Interaction and Software Engineering.
